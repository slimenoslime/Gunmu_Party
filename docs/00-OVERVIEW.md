## 1. 一句话定位

30 根滚木从山坡滚下去。摇杆控向、能跳、下坡越滚越快；速度够快时撞人能把他撞伤撞碎。
每关只留下一部分人。五关之后只剩一根。

---

## 2. 核心循环（一局的完整生命周期）

```
大厅 → 抽取第 1 关地图 → 关卡内竞速/生存/竞技 → 结算 → 晋级者进下一关 → ... → 决战 → 冠军
```

**关键结构：本游戏是「单局多阶段淘汰赛（Tournament）」，不是「单场对局」。**
一局 = 30 根滚木走完 5 关，最终 1 根冠军。中途每关结束都做一次**晋级结算**，被淘汰者观战或离开。

### 2.1 关卡与晋级表 🔒

| 关 | 名称 | 模式构成 | 进场人数 | 晋级名额 | 结算触发 |
|---|---|---|---|---|---|
| 1 | 热身赛道 | 竞速 | 30 | **25** | 25 人到线 / 时限到 |
| 2 | 山坡冲刺 | 竞速 | 25 | **20** | 20 人到线 / 时限到 |
| 3 | 二选一 | **竞速 或 生存**（抽 1 张） | 20 | **15** | 抽竞速：名额填满 / 时限到；抽生存：死亡累计达 5 人 / 时限到 |
| 4 | 三选一 | **竞速 / 生存 / 竞技**（抽 1 张） | 15 | **10** | 按抽到的模式各自结算（见 `02` §4） |
| 5 | 决战 | 竞技（禁复活） | 10 | **1** | 场上仅剩 1 人 |

淘汰曲线：30 → 25 → 20 → 15 → 10 → 1。🔒（用户口述，逐关递减）

🔒 **第 3 / 4 关是"每关抽一张图"**（用户澄清：「第三关有竞速也有生存，第四关有竞速也有生存也有竞技图，
是**三选一**，而不是子图」）：
第 3 关从「竞速 / 生存」抽 1 张，第 4 关从「竞速 / 生存 / 竞技」抽 1 张，整关只跑这一张。
**不存在"一张跑完接着跑下一张"的子图连战，也没有子图积分。**
（早期文档写成"竞速段 + 生存段"两阶段 / "三子图连战 + 积分制"，那是理解错设计的产物。）

### 2.2 晋级 = 名额制（一般化规则）🧭

"前 N 名晋级"被一般化为 **quota 名额制**，适用全部关卡与模式：

- 名额填满 → 立即结算并开下一关。
- 到线人数不足名额 → 时限到，按 **已推进度**（见 §4.4）排序补足。
- 名额是**硬上限**：第 25 人过线瞬间，其余人无论离终点多近都直接淘汰。

## 3. 三种模式（Mode）🔒

模式决定"这一张图里，碎掉会发生什么"。这是本游戏最容易出歧义的地方，因此单列。

| 模式 | 目标 | 碎掉（HP→0）后 | 有终点线 | 典型关卡 |
|---|---|---|---|---|
| **RACE 竞速** | 最快冲到终点线 | **重生到最近存档点**，回满血 | 有 | L1 / L2 / L3 前半 |
| **SURVIVAL 生存** | 活到死亡人数阈值触发 | **不重生**，计入 1 次死亡，进入观战 | 无（或终点仅作进度参考） | L3 后半 / L4 中段 |
| **ARENA 竞技** | 限时内人头最多 | L4：**无限复活**（随机出生点）<br>L5：**永久淘汰** | 无 | L4 末段 / L5 |

### 3.1 冲突收窄说明 🧭

用户原始口述同时包含两条：

1. "碎掉的滚木会重生到上一个存档点"
2. "第三关生存：死亡满 5 人后晋级"

这两条直接冲突（若能无限重生，死亡人数永远到不了 5）。**处理方式不是让新的覆盖旧的，而是收窄旧规则的适用域**：

> 🔒 **「碎掉→重生到存档点」只适用于 RACE 图。** SURVIVAL 与 ARENA 图的重生策略由本节表格单独规定。

## 4. 核心物理与战斗规则

细则见 `01-CORE-RULES.md`，此处只放必须记住的结论。

| 项 | 值 | 备注 |
|---|---|---|
| 每根滚木血量 | **100** 🔒 | 全员相同，无成长 |
| 半径 | 0.5 m | 圆柱滚木，碰撞用等效球 + 圆柱侧面 |
| 长度 | 1.6 m | 决定"滚动轴"方向 |
| 平地最高速度 | 9 m/s | |
| 下坡最高速度 | 22 m/s | 重力沿地形梯度加速，摩擦封顶 |
| 跳跃初速 | 5.4 m/s | 空中不可再跳（单段跳） |
| 重力加速度 | 16 m/s² | |
| 撞击伤害阈值 | 相对速度 **8 m/s** | 低于阈值只推开、不扣血 |
| 存档点间隔 | 每张图 3~6 个 | 位置写在地图数据里，不是运行时算的 |

### 4.1 撞击伤害（单向判定）🧭

用户口述"在高速状态撞到其他滚木则会把他撞受伤"，一般化为：

```
对每一对碰撞 (A, B)：
    vRel = |vA - vB| · cosθ        // θ 为 A 指向 B 的方向与 A 速度方向的夹角
    if vRel < 8: 只做物理弹开，无伤害
    else:
        攻击方 = vRel 更大的一方（即 cosθ 更大者）
        受击方受到伤害 = clamp((vRel - 8) * 2.0, 0, 45)
        攻击方受到反伤 = 该伤害 * 0.15
```

要点：
- **伤害只与相对速度有关，与被撞者自身速度无关**（站着不动被全速撞 = 满伤）。
- 判定是**单向的**，不会双方互伤。
- 攻击方吃 15% 反伤，避免"无脑撞人零成本"。

### 4.2 碎掉（Destroy）🧭

HP ≤ 0 → 播放碎裂 → 按模式决定重生或淘汰。重生时：
- 血量回满 100
- 速度清零、角速度清零
- **2.0 s 无敌**（半透明闪烁），无敌期间不参与撞击伤害判定，但仍会被物理推开
- 位置 = 该玩家**个人**的最近已激活存档点

### 4.3 存档点（Checkpoint）🔒

- 位置写死在地图数据的 `checkpoints[]` 里。
- 触发方式：圆柱体碰撞——滚木中心进入存档点半径 2.5 m 且**地面高度接近**即激活。
- 激活是**单调前进**的：只能更新为编号更大的存档点，不能回退。
- 激活时给 1.5 s 的加速带效果（+20% 速度）作为正反馈。

### 4.4 已推进度（Progress）🧭

用于超时兜底排名与生存图的排序。定义：

```
progress = 已激活存档点数 × 1000  +  到下一个存档点的路径进度(0..999)
```

路径进度由**地图预生成的引导折线（Guide Path）**投影得到，不是直线距离——否则弯道图会算错。

## 5. 道具与决战技（两个独立系统）

| 系统 | 获得方式 | 数量 | 适用关卡 | 细则 |
|---|---|---|---|---|
| **道具** | 地图上固定刷新点拾取 | 20 种 | 全部关卡所有地图 | `03-ITEMS.md` |
| **决战技** | 关卡开始前选择（每关可换） | 8 种 | **仅 L4 / L5** | `04-ULTIMATE-SKILLS.md` |

### 5.1 道具刷新规则 🔒

- 刷新点位置**固定写死在地图数据里**，一局内不移动、不随机。
- 开局所有刷新点各刷 1 个道具。
- 被拾取后，**原地**经过 `respawnTime` 秒重刷（每张图单独配置，默认 12 s）。
- 刷新出来的是什么道具，按**该地图的权重表**随机（同一张图每次出的东西不同，但点位永不变）。
- 每根滚木**最多同时携带 1 个道具**，用过即空。走过刷新点若背包已满则踩碎它（3 s 后重刷）。

### 5.2 决战技选择 🧭

- 进入 L4 前弹出选择界面，从 8 个里选 1 个。
- 进入 L5 **前可重选一次**（"被击杀无法复活"意味着选择权重更高）。
- 每个决战技有独立 CD。未使用时不消耗。

## 6. 地图体系 🔒

细则见 `02-LEVELS-AND-MAPS.md`。

- **同一模式有多张地图**；每张地图的**路线与机关各不相同**。
- 共 10 张图：RACE 4 张 / SURVIVAL 3 张 / ARENA 3 张。
- 地图是**数据驱动**的：由「路段序列（生成 heightfield）」+「机关列表」+「道具刷新点」+「存档点」+「出生点」构成。同一模式内的多张图必须**公平性等价**（见 §6.1）。

### 6.1 同模式地图的公平性约束 🧭

多张图随机抽，就必须保证抽到哪张都合理：

| 约束 | 要求 |
|---|---|
| 路程长度 | 同一模式内各图路径总长偏差 ≤ 8% |
| 下坡占比 | ≥ 35%（保证"下坡快速滚动"是主玩法） |
| 存档点数 | 同一模式内数量一致 |
| 道具刷新点 | 同一模式内数量一致（位置可不同） |
| 出生点 | 起跑区必须等长、无地形优势 |
| 机关难度 | 按「致死期望值」归一化，偏差 ≤ 10% |
