# 02 · 关卡流程与地图明细

> 上位文档：`00-OVERVIEW.md`。冲突以总纲为准。

---

## 1. 五关流程总图

```
L1 热身赛道   30人 ──竞速──▶ 25人
L2 山坡冲刺   25人 ──竞速──▶ 20人
L3 二选一     20人 ──竞速 或 生存（抽 1 张）──▶ 15人
L4 三选一     15人 ──竞速 / 生存 / 竞技（抽 1 张）──▶ 10人
L5 决战      10人 ──竞技·禁复活──▶ 1人（冠军）
```

---

## 2. L1 / L2 · 纯竞速

| 项 | L1 | L2 |
|---|---|---|
| 进场人数 | 30 | 25 |
| 晋级名额 | 25 | 20 |
| 时限 | 300 s | 300 s |
| 地图池 | RACE 全部 4 张中随机 1 张 | 同左 |
| 淘汰力度 | 温和 | 中等 |
| AI 难度 | EASY | EASY / NORMAL |
| 决战技 | 不可用 | 不可用 |

结算：到达终点线的人按到线顺序记名次。名额填满即结束；到线不足名额则时限到后按 `progress` 补足。

---

## 3. L3 · 二选一（竞速 / 生存）

🧭 **整关只跑一张图**，模式从池子里抽出来（玩家口径：「第三关有竞速也有生存……
是三选一，而不是子图」）。

```
20 人进场
  │
  └─ 抽签：从 { 竞速图, 生存图 } 里抽 1 张，整关就打这一张
       ├─ 抽到 RACE     → 到线即晋级（规则同 L1 / L2），时限 240 s
       └─ 抽到 SURVIVAL → 每碎 1 人计一次死亡，死亡累计 5 人立刻结算，
                          或时限 180 s 到；存活者按「血量 % → 存活时长」排序
  │
15 人晋级（名额制）
```

| 抽到 | 地图池 | 时限 | 结束条件 |
|---|---|---|---|
| 竞速 | 4 张竞速图 | 240 s | 到线人数填满 15 个名额 / 时限到 |
| 生存 | 3 张生存图 | 180 s | 死亡累计 5 人 / 只剩 1 人 / 时限到 |

> **名额是硬上限**（铁律 1）：第 3 关的晋级名额是 15，不论抽到哪种模式。
>
> ⚠️ 早期这里写成「阶段 A 竞速（锁 10 个名额）+ 阶段 B 生存（补满 15）」的两阶段连战，
> 那是理解错设计留下的，已按玩家口径改掉 —— **不是子图，是二选一**。

---

## 4. L4 · 三选一（竞速 / 生存 / 竞技）

🧭 同样是**整关只跑一张图**，模式从三个里抽。

```
15 人进场
  │
  └─ 抽签：从 { 竞速图, 生存图, 竞技图 } 里抽 1 张
       ├─ 抽到 RACE     → 到线即晋级，时限 240 s
       ├─ 抽到 SURVIVAL → 死亡累计到阈值结算，时限 180 s
       └─ 抽到 ARENA    → 限时人头赛（90 s），**本轮允许无限复活**，
                          按「击杀数 → 存活顺序」排名
  │
10 人晋级
```

| 抽到 | 地图池 | 时限 | 复活 | 排名依据 |
|---|---|---|---|---|
| 竞速 | 4 张竞速图 | 240 s | 碎掉重生到存档点 | 到线顺序 |
| 生存 | 3 张生存图 | 180 s | 碎掉即出局 | 存活顺序 / 血量 |
| 竞技 | 3 张竞技图 | 90 s | **无限复活** | 击杀数 → 存活顺序 |

🔒 **进 L4 之前选一次决战技**（铁律 6），进 L5 之前可以重选一次。
这一条不随"抽到哪种模式"变化 —— 决战技在 L4 / L5 都可用。

> ⚠️ 早期这里写成「竞速 → 生存 → 竞技 三子图连战 + 积分制」，同样是理解错设计留下的。
> 已改成三选一；随之删掉的还有 `SUBMAP_PLACE_POINTS` 的"子图积分"语义与
> `recordStageResult` 里那段"竞速段锁名额"的特殊分支。

## 5. L5 · 决战（竞技·禁复活）

| 项 | 值 |
|---|---|
| 进场人数 | 10 |
| 地图池 | ARENA 3 张随机 1 张 |
| 复活 | **不可复活**。碎掉即永久淘汰，进入观战视角 |
| 时限 | 240 s 上限 |
| 决战技 | **进入前可重选一次** |
| **普通攻击** | **本关专属**：`J` / 触屏「攻击」，70° 扇形 / 5 m / 15 伤 / 冷却 5 s（D60）。前四关不存在这个按键 |
| 胜利条件 | 场上仅剩 1 人 → 冠军 |
| 超时 | 按「剩余血量 → 击杀数 → 伤害贡献」排序，第一名即冠军 |

道具刷新同 L4（点位固定、12 s 重刷）。因为禁复活，道具是唯一的中立资源，刷新率提高 25%（`respawnTime = 9 s`）。

> 为什么普通攻击只在这一关：前四关要么在赛道上各跑各的、要么靠地形分胜负，
> 加一个 5 秒档的近身攻击只会让手感变杂；而决赛关是唯一"所有人挤在同一个场地里互撞"的关卡，
> 那里缺的正是一个**人人都有、随时能用**的输出手段。见 `01` §2.7 与 D60。

## 8. 地图数据校验（构建期断言）

每张图在注册时必须通过：

```
assert checkpoints.size() == 模式规定值
assert itemSpawns.size() == 模式规定值
assert spawnPoints.size() == 模式规定值
assert |pathLength - 模式基准| / 基准 <= 0.08
assert downhillRatio >= 0.35                  // 见总纲 §6.1
assert 每个存档点后方 30 m 内无 hammer / saw / boulder / crusher
assert 所有 itemSpawn 落在可行走面（距路中心 <= 路面半宽）
assert 出生区 30 个点两两间距 >= 半径*2 + 0.2
```

校验放在 `MapRegistry.validateAll()`，在 `GunmuPartyGame.create()` 里跑一次，失败直接抛异常——**不允许静默降级**。
