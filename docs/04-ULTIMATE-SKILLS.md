# 04 · 决战技（Ultimate Skills）

> 上位文档：`00-OVERVIEW.md`。冲突以总纲为准。
> 决战技是**唯一有主动施法 CD 的技能系统**，只在 **L4 / L5** 可用。与道具系统完全独立、可并存。

---

## 1. 通用规则

| 项 | 规则 |
|---|---|
| 选择时机 | **进入 L4 前**选 1 个；**进入 L5 前可重选 1 次** |
| 携带数 | 同时只持有 1 个（`我的世界皓宸` 可额外偷 1 个，见 §4） |
| 施放键 | 键盘 `Q` / 手柄 `RB` / 屏幕左下角技能按钮 |
| CD 逻辑 | 每关开始时 CD 冷却完毕；CD 独立于其他玩家 |
| 施法中被碎 | 技能取消，**CD 返还 50%** |
| 施法中被控 | 不中断（除非技能条文另有说明） |
| 重复选择 | 每关可换；L5 重选后 L4 的 CD 状态清空 |

**同技能多人持有**：允许。8 个技能不设唯一性限制，10 人可能全选`中国人能飞`，这本身就是战术博弈。

> **另有普通攻击**（`J` / 触屏「攻击」）：5 s 冷却、70° 扇形、15 伤，**只在决赛关可用**。
> 它**不属于本系统** —— 不占技能槽、不受"进 L4 前选技"影响、每个人进决赛关就有。
> 细节见 `01-CORE-RULES.md` §2.7。

### 2.1 每个技能都必须能打人 🔒

玩家报过：「**现在大多数技能都没有攻击能力**」。

逐条看：8 个决战技里原本只有`中国人能飞`（25 真伤）与`坤坤`（20 伤篮球）能造成伤害，
其余 6 个都是纯位移 / 防御 / 控制 / 偷窃 —— 在混战里放完一个 30 秒 CD 的技能，
除了自己变硬之外什么都没发生，体感就是"技能是假的"。

所以那 6 个各补了一段**小剂量**伤害（数值见上表）：

- 全部走 `Combat.deal`（**普通伤害**，吃刀盾 / 破防 / 蛋挞等增减伤）；
  只有`中国人能飞`的 25 点按 D15 保持真伤。
- 附加伤害都在 **8~12** 点区间，主伤害仍然来自撞击（最高 45）——
  补的是"打了但没打空"的存在感，不是把决战技变成秒杀手段。
- 近身震击（刀盾 / 扭腰 / 春秋肠）除了伤害还带**径向击退**，
  因为它们要解决的是"被人贴脸围着"这个具体处境。

## 3. 逐条精确实现

### 3.1 `spring_sausage` 春秋肠 · 回到 5 秒前的位置和血量

```
历史缓冲：
    每逻辑帧写入 Ring（容量 300 = 5s × 60Hz）
    每帧记录：{ pos, hp, velocity, yaw }

施放：
    读第 (now - 300) 帧快照
    若历史不足 300 帧 → 回滚到"进入本关卡时"的出生状态
    pos ← 快照.pos
    hp  ← max(快照.hp, 1)        // 不允许回滚成"已死"
    velocity ← 0
    施加 1.0 s 无敌

规则：
    · 快照不含：道具、增益、CD、人头数、名次
    · 只回滚「位置 + 血量」——这是用户的原话，不做扩展
    · 若回滚落点在深渊外 → 顺延到最近存档点
```

| 参数 | 值 |
|---|---|
| 回溯窗口 | 5.0 s |
| 缓冲容量 | 300 帧 |
| 回滚后无敌 | 1.0 s |
| **出发地冲击波** | **半径 5 m / 10 伤 / 击退 6 m/s** |
| CD | 40 s |

> 冲击波留在**出发地**（不是落点）：回到过去本身是逃脱技，那就让"离开"这个动作有代价 ——
> 追着你打的人会吃一下。追的人如果本来不在你原来的位置附近，什么都不会发生。

### 3.2 `dao_dun` 我的刀盾 · 攻防 +50%，持续 5 秒

```
施放瞬间：
    以自己为中心、半径 4.5 m 内所有敌人：
        12 点普通伤害 + 径向击退 8 m/s
    （这就是"刀"那一半：只加攻防的版本在混战里没有任何存在感，见 §2.1）

持续 5.0 s：
    攻击力 +50%  →  撞击伤害 × 1.5
    防御力 +50%  →  受到的所有伤害 × (1 / 1.5) = × 0.6667
```

| 参数 | 值 |
|---|---|
| 时长 | 5.0 s |
| 攻击倍率 | × 1.5 |
| 承伤倍率 | × 0.6667 |
| **施放震击** | **半径 4.5 m / 12 伤 / 击退 8 m/s** |
| 视觉 | 身侧两片旋转的刀 / 盾环 |
| CD | 30 s |

### 3.3 `haochen` 我的世界皓宸 · 复制对面的技能

```
施放：
    目标 = 面朝方向 60° 锥形内、2~20 m 处**最近的敌人**
    若范围内无人 → 退化为"全场最近的敌人"（范围同样是 20 m）
    if 目标 != null
        12 点普通伤害            // 「顺手牵羊」：偷不到也不至于白放
    if 目标.ultimate != null && 目标.ultimate != haochen
        me.stolenSlot = 目标.ultimate       // 复制
        me.stolenCharges = 1
    else
        施放失败，CD 立即返还为 50%（不空放惩罚）

使用：
    stolenSlot 的技能可随时施放，施放后 stolenCharges = 0，槽位清空
    窃取来的技能不含 CD（因为它只有 1 次）
```

| 参数 | 值 |
|---|---|
| 锁定锥角 | 60°（半角 30°） |
| 锁定距离 | 2 ~ 20 m |
| **顺手一击** | **12 点普通伤害（偷到与没偷到都会打）** |
| 可用次数 | 1 次 |
| 不可复制目标 | 自身 `haochen`（防套娃） |
| CD | 25 s |

### 3.4 `zheng_tai` 正太扭腰 · 不能动但免疫攻击，3 秒

        10 点普通伤害 + 径向击退 11 m/s（"扭腰把人甩开"）

持续 3.0 s：
    移动输入强制归零（不能移动、不能跳跃）
    免疫一切伤害（近战撞击 / 道具 DoT / 机关 / 决战技）
    免疫一切控制（眩晕 / 定身 / 击飞）
    仍参与物理推挤 —— 会被别人撞开位移
```

| 参数 | 值 |
|---|---|
| 时长 | 3.0 s |
| 移速 | 0 |
| 免伤 | 100% |
| 免疫控制 | 是 |
| 免疫推挤 | 否 |
| **施放甩开** | **半径 4 m / 10 伤 / 击退 11 m/s（击退最强的决战技）** |
| CD | 25 s |

### 3.5 `zhongguoren_fei` 中国人能飞 · 2 秒前摇 → 范围击飞

```
t ∈ [0, 2.0s)  前摇阶段：
    地面出现 2 道收缩光圈（世界空间，半径 9.0 m → 0.5 m，2 道相位差 0.5）
    期间可移动，但移速 × 0.25（即 −75%）
    期间可用道具
    被碎掉 → 技能取消，CD 返还 50%

t = 2.0s  爆发：
    以施法者为中心，半径 9.0 m 内**所有敌人**（不含自己）：
        击飞：径向速度 12 m/s + 向上 vy = 7 m/s
        伤害：25（固定，不吃任何加成，也不被任何减伤减免）
    施法者自身获得 0.5 s 站稳（不被自己的冲击反推）
```

| 参数 | 值 |
|---|---|
| 前摇 | 2.0 s |
| 前摇移速倍率 | × 0.25 |
| 作用半径 | 9.0 m |
| 击飞速度 | 径向 12 m/s + 上 7 m/s |
| 伤害 | 25（真伤） |
| CD | 35 s |

### 3.6 `niurou_mian` 忘情牛肉面 · 隐身 5 秒

```
5.0 s 内：
    其他玩家 / AI 的"锁定 / 自动瞄准 / 视野标记"完全看不到你
    AI 的寻敌目标列表里剔除你
    changsha_hot（长沙挺热）能看破
    物理碰撞依然存在（隐身不是穿模）
    受到任意伤害 → 立刻解除
    使用道具 / 决战技 / 普通攻击 → 立刻解除（攻击性动作暴露自己）
    **破隐一击**：隐身期间的撞击伤害 × 1.8，命中（打到没在无敌帧里的对手）即解除
结束：
    0.5 s 渐显
```

| 参数 | 值 |
|---|---|
| 时长 | 5.0 s |
| 免锁定 | 是 |
| 受伤即解除 | 是 |
| 主动攻击即解除 | 是 |
| **破隐一击** | **撞击伤害 × 1.8，命中即解除（D16 第一次真的有落点）** |
| CD | 30 s |

> D16 早就写了"主动攻击会提前解除隐身"，但在此之前隐身只是一个纯逃脱技 ——
> 那条规则**没有任何作用对象**。有了破隐一击，隐身才第一次真的有了攻击性：
> 贴着人撞过去特别疼，打完立刻现形。

### 3.7 `mj` · 逐渐变大的蜘蛛网

```
发射：
    沿施法方向（人物当前朝向）发射 1 张蜘蛛网投射物
    初始半径 0.8 m
    直线速度 16 m/s（不受地形影响，走直线）
    半径随时间线性增大：r(t) = 0.8 + (2.0 - 0.8) * (t / t_max)，t_max = 飞行到最大射程的时间
    最大半径 2.0 m（= 0.8 × 2.5，符合"最大是原本的2.5倍"）
    最大射程 30 m

命中敌方滚木：
    8 点普通伤害（"网住就撕"）+ 定身
    定身时长 = (命中时刻半径 r_hit / 2.0) * 3.0 s
        r_hit = 0.8 → 1.2 s
        r_hit = 2.0 → 3.0 s
    定身期间：无法移动、无法跳跃
    可被"击飞类"效果位移（网住 ≠ 免位移）
    网只命中 1 个目标（先碰到的那个）
    撞到静态墙 / 超出射程 → 消失
```

| 参数 | 值 |
|---|---|
| 初半径 | 0.8 m |
| 最大半径 | 2.0 m（×2.5） |
| 飞行速度 | 16 m/s |
| 最大射程 | 30 m |
| 定身时长 | 1.2 ~ 3.0 s（与命中半径线性相关） |
| **命中伤害** | **8**（原来只有定身，网住之后双方都只能干等） |
| 命中目标数 | 1 |
| CD | 30 s |

### 3.8 `kunkun` 坤坤 · rap 眩晕 → 篮球

t = 0.5 s    发射篮球：

                 每个目标发射 1 个篮球
                 篮球速度 8 m/s（明显低于玩家 9~22 m/s，可以被躲）
                 直线飞行，最大射程 25 m
                 命中：20 伤害 + 击退 6 m/s
                 被静态墙阻挡；不会命中自己
```

|---|---|

| rap 眩晕 | 0.5 s |
| 第二段延迟 | 0.5 s |
| 篮球数量 | 2（每个目标 1 个） |

## 4. 技能槽的数据模型

```
每个 Roll 持有：
    ultimate        : UltimateType   // 本关选的，永久持有
    ultimateCd      : float          // 剩余 CD
    stolenSlot      : UltimateType   // 仅"我的世界皓宸"会填
    stolenCharges   : int            // 恒为 0 或 1

施放优先级：
    按 Q → 若 stolenCharges > 0，先放偷来的
          → 否则放自己的（需 ultimateCd <= 0）
```

**为什么偷来的优先**：偷来的只有 1 次，不用就浪费；且避免玩家在 CD 中误以为自己按了没反应。

## 5. 与道具 / 环境的交互

| 交互项 | 规则 |
|---|---|
| 刀盾 vs 千薪万苦 | 乘算：`伤害 × 1.5 × (1 + (1−HP%)×0.6)` |
| 刀盾 vs 破防 | 乘算后减伤：`× 1.35 × 0.6667` |
| 正太扭腰 vs 中国人能飞 | 免疫伤害，但仍被**击飞位移**（扭腰不免疫推挤）。伤害数字显示为 0。 |
| 正太扭腰 vs mj | 完全免疫定身与伤害 |
| 隐身 vs 坤坤篮球 | 发射瞬间若目标隐身 → 该篮球不发射（找不到目标）；发射后隐身 → 篮球仍追踪不到，直线飞过 |
| 春秋肠 vs 碎掉 | 已碎的玩家不能施放；回滚的 hp 至少为 1 |
| 复制 vs 复制 | 不能复制 `haochen` 自身，但**可以复制别人偷来的技能**（偷来的技能是"使用一次消失"的，复制过来同样只有 1 次） |
| 决战技 vs 道具 CD | 完全独立，互不影响 |
